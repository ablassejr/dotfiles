# Local reduction protocol

The user identifies the repository and the outcome that must survive. Reuse the user's stated consumers, environments, invariants, retirements, and authority to experiment. When an unresolved fact changes what can be removed, explain the uncertainty and resolve that decision before the dependent change. A report's example or recommendation is not a new obligation by itself.

The inventory records every file without executing repository configuration. A reviewed classification policy identifies maintained production code, tests, tooling, executable configuration, supporting documents, generated output, supplied dependencies, and excluded material. Exclusions have an explicit reason. Files without a matching classification remain visible as unclassified. Git metadata is hashed separately and never counted as maintained source.

The snapshot keeps the approved source independently from the original. It hashes ordinary files, untracked files, modes, symlink targets, and Git metadata. Linked worktrees include their referenced Git metadata. No Git hooks run. Unclassified material remains an analysis gap; a runnable copy cannot include unresolved symlinks or special files. Do not reset, stash, commit, or discard changes to make an audit easier.

The agent builds a structural map from actual imports, calls, exports, registrations, configuration, and analyzer outputs. It then connects these facts to obligations, authoritative owners, and supporting mechanisms in the candidate records. Include public APIs, dynamic loading, migration and build entry points, tests, supported variants, and external consumers. An open library's locally unused public export is not evidence of retirement. Absence from a runtime trace is also insufficient.

For an uncertain mechanism, inspect its introducing and changing commits, tests, ADRs, comments, and supplied requirements. Distinguish a current obligation, replaceable implementation, obsolete constraint, temporary workaround, accidental structure, and unknown rationale. Missing history does not authorize deletion. Remote discussions remain missing if the local workflow has no supplied copy.

The candidate explains its target in complete sentences and identifies every proposed removal path. When multiple candidates claim a path, `plan.py` reports that overlap and counts the path once. The helper orders explicit dependencies and blocks dependents of unresolved candidates. Source reduction estimates remain UNKNOWN until they are grounded; file count is not a source-line estimate.

After an authorized experiment and current verification, recompute the affected dependencies and newly orphaned helpers, fixtures, configuration, and packages. Repeat while a supported, meaningful reduction remains. Preserve the smallest useful contract tests and dependency rule that protect the result. Stop when further reduction would remove required behavior or merely hide complexity.

The JSON files are the local continuation record. On resumption, recheck the original, baseline, candidate, policy, and evidence hashes. A changed snapshot requires new evidence. Nothing in a recorded plan authorizes a remote publication or an original-repository edit.
