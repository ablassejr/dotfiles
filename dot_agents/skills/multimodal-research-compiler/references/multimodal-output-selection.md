# Multimodal output selection

Choose the smallest set of projections that materially improves understanding or handoff.

| Information structure | Preferred projection |
|---|---|
| Direct conclusion and evidence | Durable narrative and structured records |
| Chronology and evolution | Timeline |
| Decision provenance | Decision-lineage graph |
| System boundaries and dependencies | LikeC4 or another formal architecture model |
| High-fidelity explanation | Figma design frame |
| Alternative comparison | Comparison frame or table |
| Code-level reasoning | Cited excerpts, diffs, and structural view |
| Work ownership and state | Linear decision packet or issue update |
| Machine handoff | JSON Research Packet |
| Short-lived scratch work | Temporary Markdown |
| Cross-session continuity | Research Session Manifest |

Do not create every modality. Prefer a direct answer plus the one view that exposes the important relationship. External publication remains subject to the user's authorization and the destination's read-back verification.
