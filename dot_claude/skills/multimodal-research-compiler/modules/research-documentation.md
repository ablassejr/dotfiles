# Research official documentation

Use Docs MCP Server for exact CLI, API, dependency, protocol, platform, deprecation, and migration claims.

Resolve the repository-pinned or user-specified version before searching. Prefer the owning project's official documentation, specification, or source release. Record the exact version or applicable range, publication or retrieval date when relevant, and the section that supports each claim.

Before invoking a CLI, retrieve documentation for the intended command, arguments, flags, and side effects and build the invocation from that evidence. If the applicable documentation is absent or stale, refresh or index the official source and wait for completion. If it remains unavailable, mark the invocation blocked instead of guessing.

Separate a documented guarantee from observed behavior and from a migration recommendation. A current latest-version page does not establish behavior for an older pinned dependency.
