# Frame the request

Translate natural language into the `research-request.schema.json` contract without inventing constraints.

Record the root question, the decision or action it supports, audience, mode, desired confidence, first-principles basis, semantic and implementation authorities, source and time boundaries, applicable versions, requested outputs, and explicit non-goals. Preserve user wording for normative goals and constraints.

Infer an omitted value only when the active workflow makes it unambiguous. Mark the inference in `assumptions`. Ask one concise question when the answer would materially change what is researched, what evidence is permitted, or whether an external write is authorized. Missing optional output preferences do not block framing.

Before continuing, state the framed question, current assumptions, authority boundary, and what successful research will enable. Do not present a candidate answer at this stage.
