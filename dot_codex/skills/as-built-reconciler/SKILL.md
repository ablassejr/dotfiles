# As-built reconciler

For human interactions and team outputs, follow [review and artifact design](../epic-spec-workflow/references/review-and-artifact-design.md). Read it before preparing a question, review, publication, or handoff.

Invoke `$specification-reconciliation` and stop before artifact deletion. Resolve the approved specification revision, delivery program, merged pull requests, repository baseline and final revision, Code Mass Opportunity Maps, deletion Grounding Packets, issue contracts and audit reports, milestone ledgers, view registry, ADRs, and provenance manifest.

Verify integrated behavior at public boundaries and compare every affected semantic ID with the merged result. Treat a mismatch as an implementation defect or proposed semantic change; do not silently edit records to make them agree.

Recalculate final production, test, and combined normalized SLOC from committed milestone baselines. Remove credit for reverted deletion, relocation, unrelated cleanup, test erosion, hidden complexity, or any removal that lacks validated provenance. Update every milestone ledger with the as-built issue results. A milestone reaches completion only at 6:5 or through its explicit project-level exception; otherwise retain or create visible code-mass debt in the same responsibility domain.

Update the selected authoritative documentation and affected LikeC4, Archify, or Figma Design graph projections and any non-graph FigJam material to the verified current state. Fetch every external write, inspect rendered visuals, and obtain the required human approval. Record an ADR only when the repository's existing threshold applies. Return verified revisions, links, acceptance evidence, final code-mass results, ledger status, exceptions or debt, mismatches, and residual risks for `$repository-artifact-cleaner`.

## Graph visual gate

Apply the shared [graph visual policy](../epic-spec-workflow/references/graph-visual-policy.md) to every graph-like output. Use Figma Design, LikeC4, or Archify and retain matching render-operation and artifact evidence. Include all produced or published visuals in the current step’s inventory and run `specflow validate-visuals <manifest.json> --json` before presentation. A missing renderer or invalid receipt blocks the visual output. Non-graph media keep their own communication purpose.
