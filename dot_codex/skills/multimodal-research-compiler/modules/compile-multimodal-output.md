# Compile multimodal output

Start from the reviewed Research Model and select only the outputs required by the request or materially useful to the audience.

Create the direct answer and machine-readable Research Packet first. Then project chronology as a timeline, decision provenance as a lineage graph, formal boundaries as an architecture model, alternative comparison as a table or frame, and high-fidelity explanation as a design frame when those structures are present. Use the templates as starting shapes, not as evidence.

Every projection carries its view identifier, research release, model digest, and referenced claims, basis, and decisions. Visual emphasis must match recorded confidence and contradiction state. A destination-specific narrative may omit detail but cannot change meaning.

Keep the understanding checkpoint separate from the decision checkpoint. The first asks whether the reconstructed model is accurate. Only after that is confirmed should the second ask what to do. If the user requests deeper grounding, return to the same unresolved question after updating the model.

Write external artifacts only within authorized scope. After a write, read back the exact destination artifact and compare it with the model. Publication is incomplete if read-back fails. Persist the session manifest at each pause and release, then remove temporary scratch artifacts only after durable outputs are verified.
