# Compile context

Create one Research Context Capsule so later researchers and resumed sessions share the same starting point.

Resolve and pin only sources allowed by the request: the approved First-Principles Basis, specification release, current issue and related native relations, repository and base commit, pull request, architecture-model revision, attached files, previous packets, and relevant dependency versions. Record unavailable sources rather than silently omitting them.

Identify the initial entities, starting sources, required claim families, and dependent questions. Separate semantic authority, current implementation evidence, historical evidence, and explanatory visuals. A visual can identify a question but cannot establish semantic truth merely because it was supplied.

Emit a capsule conforming to `schemas/context-capsule.schema.json` with phase `INPUT_COMPILED`. Include a source snapshot suitable for later drift checks and no secret values.
